# Модуль обработки данных (ML Logic)

Модуль предназначен для автоматического анализа и структурирования контента, собранного парсером. Он преобразует неструктурированный текст постов в конкретные атрибуты товара (цена, категория), используя классические методы обработки естественного языка (NLP).

### Ключевой функционал:
* Price Extraction — Многоуровневое извлечение цены с помощью регулярных выражений (RegEx). Система распознает различные валюты (₽, $, €) и форматы записи, отсеивая аномальные значения.
* NLP Preprocessing — Очистка и нормализация текста с помощью библиотеки NLTK. Включает токенизацию, удаление стоп-слов и стемминг (приведение слов к их корню).
* Fuzzy Matching — Нечеткий поиск категорий, устойчивый к опечаткам, сленгу и различным вариантам написания названий брендов.
* Batch Processing — Асинхронная обработка очереди записей из базы данных для эффективного обновления каталога.

### Технологии и методы:
* Python 3.11+
* NLTK (Natural Language Toolkit) — Токенизация и стемминг (Snowball) для качественной обработки русского языка.
* FuzzyWuzzy (алгоритм Левенштейна) — Вычисление степени сходства строк для сопоставления категорий.
* RegEx (библиотека re) — Сложные паттерны для поиска числовых данных и валютных маркеров.
* Asyncio — Асинхронная работа для бесшовной интеграции с ядром базы данных.

### Основные функции:
* extract_price(text) — Извлекает наиболее вероятную цену, анализируя контекст валют и числовые диапазоны.
* detect_category(text) — Определяет категорию товара, используя комбинацию стемминга и нечеткого сравнения по расширенным словарям синонимов.
* clean_text(text) — Предварительная очистка данных: удаление эмодзи, ссылок, Telegram-упоминаний и лишней пунктуации.
* process_posts() — Главный цикл-обработчик, осуществляющий связь между модулем обработки и core/database.py.
