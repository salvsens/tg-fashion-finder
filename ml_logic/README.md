# Модуль интеллектуальной обработки данных (ML Logic)

Данный модуль отвечает за автоматический анализ, очистку и структурирование текстовых данных, поступающих из fashion-каналов. Он превращает сырой текст постов в структурированные атрибуты базы данных (цена и категория) с использованием методов NLP (обработки естественного языка).

### Ключевые возможности:
* **Advanced Price Extraction**: Умное извлечение цены, поддерживающее:
    * Форматы с "к" (например, `15.5к` -> `15500`).
    * Различные валюты (₽, $, р., usd).
    * Автоматическое определение статуса **«Продано»** при нахождении ключевых слов (sold, забрали).
    * Фильтрацию аномалий (игнорирование слишком маленьких или больших чисел, которые могут быть размерами или ID).
* **NLP Pipeline (NLTK)**:
    * **Токенизация**: Разбиение текста на отдельные смысловые единицы.
    * **Стемминг (Snowball)**: Приведение слов к корню для учета морфологии русского языка (например, «кроссовки», «кроссовок» и «кроссовками» распознаются как одно понятие).
    * **Stop-words**: Исключение «шумовых» слов (как общеязыковых, так и специфических для fashion-ритейла: *размер, доставка, в наличии*).
* **Fuzzy Matching**: Нечеткое сопоставление категорий на основе алгоритма Левенштейна. Позволяет корректно определять категории даже при наличии опечаток или сленговых выражений.

### Технологический стек:
* **Python 3.11**
* **NLTK (Natural Language Toolkit)**: Основной инструмент для лингвистического анализа.
* **FuzzyWuzzy**: Библиотека для нечеткого сравнения строк (score-based matching).
* **RegEx**: Сложные регулярные выражения для глубокой очистки текста и парсинга цен.

### Основные функции:
* **`detect_category(text)`**: Трехуровневая система классификации:
    1. Проверка по базе стеммированных слов (самая быстрая).
    2. Точное совпадение оригинальных ключевых слов.
    3. Нечеткий поиск по словарю синонимов (порог уверенности — 75%).
* **`extract_price(text)`**: Многоэтапный парсер цен с защитой от "мусорных" чисел и обработкой разделителей (точки, пробелы).
* **`clean_text(text)`**: Глубокая очистка данных: удаление эмодзи (через Unicode-диапазоны), ссылок (http/t.me), упоминаний (`@user`) и хештегов.
* **`process_posts()`**: Асинхронный воркер, который забирает из базы записи со статусом `is_processed=0`, обогащает их данными и сохраняет результат.

### Поддерживаемые категории:
Система автоматически классифицирует товары по следующим направлениям:
* `shoes` (обувь, кеды, sneakers...)
* `hoodie` (толстовки, свитшоты, кофты...)
* `outerwear` (куртки, пуховики, бомберы...)
* `pants` (штаны, джинсы, карго...)
* `t-shirt` (футболки, майки, топы...)
* `accessories` (кепки, сумки, очки, часы...)
