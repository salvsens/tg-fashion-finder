# Модуль Telegram-бота (`/bot`)

Данная директория содержит программный код основного интерфейса взаимодействия с пользователем для поиска и агрегации fashion-предложений.

### Структура файлов:
* **`main.py`**: Точка входа в приложение, конфигурация диспетчера и запуск асинхронных задач.
* **`__init__.py`**: Инициализация модуля.

### Ключевые функции и задачи:
* **`cmd_start`**: Приветствие пользователя и краткий онбординг по функционалу поиска «дрипчика».
* **`cmd_search`**: Полнотекстовый поиск по базе данных. Реализована логика ограничения вывода (до 5 позиций), обработка статуса «Продано» (при отсутствии цены) и санитайзинг HTML-тегов для предотвращения ошибок Telegram API.
* **`scheduler`**: Асинхронный фоновый воркер. Каждые 5 минут инициирует вызов `process_posts` из модуля `ml_logic` для обогащения данных (извлечение цен и категорий) без блокировки основного потока бота.
* **`handle_channel_post`**: Регистрация хендлера для автоматического мониторинга и сохранения постов из подключенных Telegram-каналов.
* **`get_like_keyboard` & `process_like`**: Система взаимодействия с контентом через `Inline`-кнопки и `callback_query`.

### Безопасность и отказоустойчивость:
* **HTML Escaping**: Использование библиотеки `html` для экранирования пользовательского контента, что исключает падение бота при наличии спецсимволов (`<`, `>`, `&`) в описании товара.
* **Error Handling**: Обертки `try-except` в блоках отправки медиа-контента и в планировщике задач для обеспечения работы бота 24/7.
* **Environment Variables**: Полная изоляция чувствительных данных (токены, пути) через переменные окружения и файл `.env`.

### Технологии:
* **`Aiogram 3.x`**: Современный асинхронный фреймворк для реализации логики бота.
* **`Aiosqlite`**: Асинхронный доступ к SQLite, обеспечивающий высокую скорость отклика при конкурентных запросах.
* **`Python-dotenv`**: Управление конфигурацией окружения.
* **`Asyncio`**: Управление конкурентными задачами (поллинг и планировщик).
